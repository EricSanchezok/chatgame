# 自主 Agent 名册

## 选择尺度

运行世界包含 47 个初始自主 Agent。入选者必须能在没有玩家介入时改变领土、联盟、资源、信息或长期危险；普通居民、守军、船员、商队、兽群和只体现即时威胁的怪物保持为聚合实体。全体 Agent 每个世界步骤都行动，因此名册不把“有名字”误当成“需要独立心智”。

来源栏中的“移植”表示原作给出姓名与职位；“原创领导”表示原作给出机构但没有负责人，改编为机构补充一个可行动代表。人物动机在不改变原作关系的前提下由其职位、现场局势与公开性格推演。

## 非 Agent 主体

Lake King、Tavis、鎏金机仆、三位彼此独立的 nixie 姐妹，以及源文中的守军、兽群、怪物、亡灵和生态共同体都以 canonical entity 或明确的聚合实体存在。聚合实体保存人数、位置、职责与可变状态，但不伪装成共享心智；它们可以被 Truth Engine 观察、移动、伤害、分裂或转化。只有某个具体主体在运行中取得持续自主目标，并通过合法状态操作成为 Agent 后，才进入每步联合行动。
