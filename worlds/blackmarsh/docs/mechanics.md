# 机制与数值标尺

## 设计边界

黑沼不移植 D&D 的职业、等级、六维属性、AC、法术位、先攻或固定怪物 HD。所有自然语言行动保持开放；只有会因精确数值、守恒、阈值或随机承诺而受益的状态进入 [`world/mechanics.yaml`](../world/mechanics.yaml)。

行动先由语义裁决为 `none/minor/standard/major/decisive` 效果档，再由 `harm` 或 `recovery` impact profile 映射为 vitality 变化。木棒、剑、火焰、护甲和沙土不是核心类型：它们只有在 ActionFrame 明确使用且能落到 Entity、Fact、Condition、placement 或法则时才承担 permission、control、potency、protection、secondary 或 risk 中的唯一角色。校准语料是 planner、verifier 与测试共享的世界标尺；它不把示例变成封闭动作列表。

## 生命 Meter

`vitality` 范围为 0–30，零触发 `retired`。它表示继续作为活动主体承受危险的能力，不把每次擦伤解释成肉体创口；Truth Engine 仍须依据武器、体型、防护、环境和检定说明伤害因果。

| 初值 | 叙事标尺 |
|---:|---|
| 8–11 | 缺乏战斗经验、体弱或容易被一次严重危险击倒 |
| 12–16 | 健康平民、旅行者或普通战士 |
| 17–21 | 经验丰富的指挥官、猎手或施法者 |
| 22–25 | 顶尖凡人、强化生物或小型超自然强者 |
| 26–29 | 巨龙、强大元素体与地区级怪物 |
| 30 | 本世界开局可表达的单体承伤上限，不代表无敌 |

## Rating

每个 Rating 定义范围为 -3 至 8。实体只持有真正能影响其行动的 Rating；没有某项 Rating 不等于数值零，而是裁判不能把该实体的专长当作结构化修正来源。

| 值 | 能力标尺 |
|---:|---|
| -3 至 -1 | 明显受限或处于不利状态 |
| 0–1 | 未经专门训练到可靠日常能力 |
| 2–3 | 受训者、职业人员或有经验的地方领袖 |
| 4–5 | 地区知名专家、资深指挥官或强力施法者 |
| 6–7 | 世代少见的能力或超自然专长 |
| 8 | 设定内顶点；只有极少数主体在单一领域达到 |

`force` 处理直接力量与强攻，`finesse` 处理精细动作、潜行与敏捷，`resolve` 处理恐惧、痛苦、诱惑与长期意志，`insight` 处理判断、调查和识别欺骗，`influence` 处理说服、声望和社会施压，`craft` 处理制造、修复和专业技术，`wilderness` 处理追踪、野外生存与自然知识，`command` 处理组织多人、纪律和战术协调，`magic` 处理施法、仪式和奥术理解，`seamanship` 处理航行、海况和船队行动。

## Quantity

`viz` 以“份”为单位。一份是足以支持一次低强度施法或作为更大制作的一部分的实体魔力；高强度效果可以消耗多份。开局数量只记录已经分离、可以持有或交易的 Viz，仍在瀑布、灰种、矿脉、虫卵或贝壳中的潜在来源以世界事实存在，取得后才能依据 `viz-cycle` 生产。

`coin` 以金币等价单位表示可支配钱币，不追踪每种铸币。价格仍由语境决定；转移保持守恒，收入、铸造和发现宝藏必须引用 `coin-economy`。

`provisions` 以一名普通体型旅行者的一日份为单位。大队人马的库存放在聚合实体而不是每个成员；消耗和补给引用 `provisions-cycle`。

## 时间与事件截止

运行时从 `elapsedSeconds = 0` 开始，代表初秋日落前约两小时。只有已经具备行动主体、唯一 `operation-state`、唯一 `operation-target` 和可核时间压力的跨地点行动才记录数值截止；`deadline-seconds` 是绝对 elapsedSeconds 阈值，不是每步递减的剩余量。开局三项是 Sigrun 进军、Rinisar 驱赶八首 Hydra 与 Ochre 搜索船抵达；同名 `world_timers` 把这三个阈值接入 Temporal Kernel，并只唤醒各自有权结算的 Agent，不预存结果 delta。`deadline-integrity` 要求达到或越过截止的同一原子提交把状态更新为 `implemented`、`blocked` 或 `cancelled` 并移除截止，或以新因果依据替换截止，不能继续保持 `preparing` 或 `in-progress`。Egil 的日出袭击仍是其 Agent 意图，是否执行由联合行动裁决，不另建自动时钟。

自然日历不是第四个行动截止。开局月相锚定为盈凸月，距下一次满月 `518,400` 秒；以后按 `2,551,443` 秒的朔望周期重复。月贝、Tave 仪式与黑堡现象共同消费这一个日历事实，达到或越过节点时由 `lunar-calendar` 约束原子结算，而不是各写一套互相漂移的倒数。`blackmarsh-last-settled-full-moon-node` 从 -1 起提供唯一幂等凭据；Tave 仪式圈记录最后集会节点而不改变表示成员常态分散范围的 placement；黑堡另记录自身最后评估节点，以区分“已检查但无人可受害”和“漏结算”。两项秒数是运行改编的显式选择，并非来源给出的 Blackmarsh 日期。

没有明确截止的遗迹、怪物巢穴和生态危险是持续状态。随机遭遇概率不逐字移植；对应地域的生物密度、习性和可见迹象成为裁判判断遭遇是否合理的事实。

来源明确规定随机分布时不抹掉分布。月贝每次满月的 Viz 产量采用四次独立六结果承诺之和，边界为 4–24；Oldan Hold 当期外来商人采用五次独立十结果之和，边界为 5–50，来源没有季节限定；0318 每小时以四个等概率结果中的一个触发遭遇，触发后野猪数为四次独立四结果之和，即 4–16；0302 每百码以六个等概率结果中的三个触发，触发后四个结果指向蛇穴、两个指向活动巨蛇。需要具体值时先产生可复现随机承诺，再把结果与当期库存、访客或遭遇事实原子提交，不能把期望值、任意常数或尚未发生的产出写进开局状态。

## 聚合与个体

人口、守军、船员、商队和兽群是可移动、可受损、可分裂的聚合实体，但不拥有单一人的 `vitality`。若一次行动需要精确结算集体损失，Truth Engine 应先以事实、事件和可验证的数量变化表达，不把一个人的生命 Meter 复制成军队血条。

地点只拥有坐标、稳定地貌/建筑与现场证据；组织或移动种群唯一拥有人数、编成与当前状态；Agent 的目标和 belief 唯一拥有意图与认知。聚合实体不共享全知心智，若互动需要区分成员，先从聚合体创建具体个体，再给各个体独立状态。
