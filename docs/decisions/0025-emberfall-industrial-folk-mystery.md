# 《灰烬镇》工业民俗悬疑重做

## Status
Proposed
Class: feature

## Context and Problem Statement

《灰烬镇》的实体与 schema 覆盖较广，但玩家身份、矿井、煤精、任务、证据和社会关系没有形成可持续循环；多个身份、动作、任务与秘密路径不可达。棕色几何 SVG 与通用按钮也没有表现劳动、民俗和蒸汽魔法。

## Decision Drivers

- 玩家在十五分钟内完成一次有准备、风险、带回与结算的矿井班次。
- 煤精、公共炉和证据成为可验证的世界系统。
- NPC 由职责、欠账、承诺和主动计划驱动，而不是功能位与好感阈值。
- 视觉、声音和交互来自矿镇真实材料与劳动仪式。

## Considered Options

- 保留现有内容，只补更多事件与美术。
- 改成线性矿难推理剧情。
- 重做为工业民俗悬疑与矿井轮班的系统型世界。

## Decision Outcome

玩家接管全镇唯一公用灰灯，作为矿井见证人与巡查者，在班前准备、井下行动、带回资源/证据和周期配火之间循环。煤精在矿灯、诊所、排水泵、公共炉、锻炉和商队之间守恒；核心结论至少由两种独立来源互证。

剧本通过 UI API v3 提供班次 HUD、矿层剖面、承诺账与证据来源图，通过 Engine Extension v2 在自身 `runtimeState` 维护灯火、灰蚀、炉存、矿层压力和周期结算。视觉采用煤尘账簿、木刻/石版纹理、氧化铜与旧纸，青白灰火是唯一超自然高亮。

先交付两出身、四 NPC、两派系、一个地面枢纽、三个矿点和一次完整班次的 vertical slice；循环通过后再扩展到完整世界。无结果动作、不可达路径和模板化旧素材直接删除。

## Pros and Cons of the Options

### 补内容与换皮

- 好：改动较小。
- 坏：保留断裂循环与不可达规则，只会扩大无效内容。

### 线性推理剧情

- 好：节奏易控制。
- 坏：揭谜后失去长期玩法，违背世界型剧本定位。

### 系统型矿镇

- 好：资源、关系、调查与周期后果互相驱动，可长期游玩。
- 坏：需要更多确定性系统、平衡模拟和独特资产。
