# 测试政策

本仓库如何分层测试，以及让绿色套件保持有意义的规则。命令住在根 [AGENTS.md](../AGENTS.md)。

## 层级

- **单元**（`npm test`）：快速测试，跟随其覆盖的代码区域。优先边界情况、错误路径、事件顺序与并发竞态。
- **集成**：测试真实组合（真实模块接在一起，外部服务只在昂贵或非确定性边界 mock）。
- **端到端**（`npm run play` / `npm run script:validate`）：启动真实入口并验证世界——重跑命令或从外部重读文件，绝不依赖程序自身声称。

## 规则

- **验证世界，而非自述**。端到端断言重跑命令或从外部重读文件；在程序自身输出上做关键词探测会让坏构建通过。
- **测试真实入口路径**。优先启动真实二进制/模块而非手工接线 harness；手工 fixture 只证明桥在搬运字节，不能证明交付物行为正确。
- **只 mock 边界**。Mock 昂贵或非确定性边缘（网络、时钟、外部 API）；其余保持真实。
- **测试描述行为，而非正确性**。行为过时随测试一起改；在改动里说明原因。
- **不该触碰的文件断言字节一致**：改动不该影响的文件保持逐字节相同。
- **恢复测试按步骤分离失败前后**：证明失败块无副作用。

## 何时需要测试

每个非平凡行为改动在同一改动内新增或更新测试。没有回归测试的修复只是传闻。
