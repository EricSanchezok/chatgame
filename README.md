# chatgame

剧本驱动的 AI 聊天游戏框架：加载不同"剧本"即成为完全不同的游戏；同一剧本每次开局体验不同；一个剧本就是一个可以无限游玩的世界。

## 快速开始

```sh
npm install
npm run dev
```

打开 http://localhost:3000。
